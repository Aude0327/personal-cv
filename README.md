## About the Project

This is a simple, responsive personal CV webpage created as part of a programming/project activity. It presents a short Curriculum Vitae with a profile, education, skills, practical experience, personal strengths, and contact information.

## Features

* Responsive design (desktop, tablet, and mobile)
* Personal profile
* Education section
* Skills section
* Practical experience
* Contact information
* Smooth scrolling
* Subtle animations

## Technologies Used

* HTML5
* CSS3
* JavaScript
